# Machine Learning Basics

This folder contains introductory machine learning examples, focusing on linear regression.

## Contents

- `first.py`: A Python script implementing a simple linear regression model to predict weight based on height, using `scikit-learn` and `matplotlib`.
- `First.ipynb`: A Jupyter Notebook containing the same linear regression example.

## Prerequisites

To run the code, ensure you have the necessary libraries installed:

```bash
pip install scikit-learn matplotlib
```

## Running the Code

You can run the Python script directly:

```bash
python first.py
```
